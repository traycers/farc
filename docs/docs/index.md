# farc

**farc** — система архивирования данных (видео, звук и другие потоки) на диск с использованием **фблоков** — самодостаточных блоков фиксированного размера. Запись циклическая: по истечении срока хранения старые фблоки перезаписываются новыми данными.

## Ключевые идеи

- **Фблок** — логическая единица данных фиксированного размера. Самодостаточен: читается без метаданных других фблоков и глобального заголовка, адресуется арифметически (`index * block_size`), идентифицируется UUID.
- **Фчанк** — часть фблока (4–16 МБ), единица записи с верификацией (write-verify).
- **Хранилище (Storage)** — файл или блочное устройство до 20 ТБ и более; один логический писатель и несколько читателей, запись имеет приоритет над чтением.
- **Ленивая инициализация** — ввод диска в эксплуатацию занимает секунды независимо от размера.
- **Каталог** — необязательная копия заголовков на быстром SSD для старта за секунды.
